# CashewIQ — demo

Clickable HTML/CSS/JS prototype of a cashew processing, grading, quality, inventory and export-fulfilment system.
All records are fictional sample data held in memory.

## Run

```bash
python -m http.server 5173 --directory demo
```

Open http://localhost:5173, pick a role, sign in, then click **▶ Guided tour**.

## Contents

- `demo/` — the app (`index.html`, `styles.css`, `data.js`, `app.js`)
- `Tenzok_Cashew_Intelligence_Codex_Blueprint.xlsx` — planning workbook the demo is based on
- `.claude/launch.json` — local preview server config
